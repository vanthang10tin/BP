# BDD100K workflow walkthroughs

Four disjoint, authentic 50-frame packs: two BBox detection packs and two semantic-segmentation mask packs. Each child README has exact upload steps and limitations. BBox `poly2d` reference examples are separate under `test-data/bdd100k-poly2d-reference`; they are not segmentation. BDD100K media/annotations remain subject to upstream terms.
